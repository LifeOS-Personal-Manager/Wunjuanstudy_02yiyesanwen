# 自动索引验证清单

验证日期：2026-09-01  
接口：中文维基文库 MediaWiki API + Brave Search API + DeepSeek API  
流程：维基文库优先 -> Brave 全网候选 -> 网页正文抓取 -> DeepSeek 版本核验；无公开候选 -> DeepSeek 索引并补全文 -> DeepSeek 六卡分析

## 已确认可自动索引

以下篇目已确认存在独立页面，页面 HTML 可正常取得，适合作为线上验收样本：

| 散文 | 作者 | 维基文库页面 |
| --- | --- | --- |
| 背影 | 朱自清 | `背影` |
| 荷塘月色 | 朱自清 | `荷塘月色` |

输入篇名和作者后，系统会自动搜索候选并创建项目，不需要手动粘贴原文。

## 当前未找到独立全文页面

以下篇目在当前维基文库索引中没有可直接抓取的独立全文页面：

- 故都的秋（郁达夫）
- 荔枝蜜（杨朔）
- 济南的冬天（老舍）
- 白杨礼赞（茅盾）

这类篇目会先在配置 `BRAVE_SEARCH_API_KEY` 后继续走全网候选搜索；仍无候选时由 DeepSeek 索引并补全文。AI 补全文会以独立标签和版权说明展示，不能视作已核验的权威版本。网页可访问不等于获得转载授权，发布前仍须核验版权。

## 验收方法

1. 登录线上站点。
2. 依次输入已确认篇目中的任意一篇和作者。
3. 点击 `自动索引并生成六卡`。
4. 检查项目中完整原文已填充，且六张图卡的短摘均能在原文中逐字命中。
5. 检查顶部状态为 `已保存到 D1`。

## 代码位置

- 前端自动创建流程：`src/App.tsx`
