# 散文贴图生产台使用 SOP

版本：1.0  
适用系统：散文贴图生产台 Cloudflare Pages 线上版  
正式地址：https://essay-image-studio.pages.dev/

## 1. 登录系统

1. 打开正式地址。
2. 使用已配置的邮箱完成 Cloudflare Access 验证。
3. 登录后进入工作台。

顶部状态说明：

- `已连接 D1 / R2`：当前项目使用云端数据和对象存储。
- `案例 · 本地保存`：当前是内置演示案例，不会写入云端。
- `正在保存`：正在同步数据。
- `已保存到 D1` 或 `图片已保存到 R2`：云端保存完成。

## 2. 新建散文

1. 点击右上角 `+ 新建散文`。
2. 输入散文名称和作者。
3. 点击 `检索公开原文`。
4. 核对候选版本的作者、来源、正文和版权说明。
5. 点击 `确认此版本并生成六卡`。

系统会自动保存完整原文、调用 DeepSeek，并生成 6 张图卡：1 张封面、4 张正文、1 张结尾。

原文短摘必须逐字来自用户录入的完整原文，不能由 AI 改写或补写。

## 3. 检查和编辑图卡

在 `图卡` 页面逐张检查：

- 图卡顺序和类型
- 原文短摘
- 编辑导读
- 场景描述
- 生图提示词
- 原文定位状态

点击 `编辑图卡` 可以修改内容。保存时系统会验证短摘仍存在于完整原文中；验证失败时不会保存。

### 3.1 重新生成单卡

在图卡编辑页点击 `重新生成单卡`。DeepSeek 只会重新生成编辑导读、场景描述和生图提示词，原文短摘保持不变。

### 3.2 重新分析整篇散文

在图卡页面点击 `AI 分析`。适合原文有较大修改、六卡结构不理想或需要重新生成全部分析结果的情况。

## 4. 复制和下载提示词

进入 `提示词` 页面，可以：

- 复制单条提示词
- 复制全部提示词
- 下载 Markdown 提示词清单

推荐将提示词逐条复制到外部图片生成平台。生成图片时要求竖版构图、无文字、无水印，并尽量保持 3:4 比例。

建议文件名：

```text
01-cover.png
02-body.png
03-body.png
04-body.png
05-body.png
06-ending.png
```

## 5. 批量上传和匹配图片

进入 `图片` 页面，点击 `批量上传`，选择外部生成的图片。

系统会优先根据文件名中的 `01` 至 `06` 匹配图卡；没有编号时按选择顺序匹配。

支持格式：`JPEG`、`PNG`、`WebP`。单张图片不能超过 10 MB，像素总量不能超过 4000 万。

### 5.1 单张替换

1. 找到需要替换的图卡。
2. 点击该卡的 `替换`。
3. 选择一张新图片。

系统只替换当前图卡，不会覆盖其他图片。

## 6. 自动排版

进入 `排版` 页面，选择图卡并调整：

- 图片缩放
- 图片焦点 X / Y
- 文字横向和纵向位置
- 文字宽度
- 字号
- 遮罩浓度

输出画布固定为 `1080 × 1440`。

系统提供封面、正文和结尾三种模板。检查文字是否遮挡主体、边缘是否留有安全区域，以及手机预览时是否清晰可读。

## 7. 导出发布包

进入 `导出` 页面，导出前确认：

- 图卡数量为 6 张
- 6 张图卡都有原文定位
- 6 张底图均已匹配
- 原文短摘全部验证通过
- 发布文案已填写
- 输出尺寸为 1080 × 1440

选择 PNG 或 JPG，然后点击 `一键导出 ZIP 发布包`。

发布包结构：

```text
散文名称/
├─ images/
│  ├─ 01-cover.png 或 jpg
│  ├─ 02-body.png 或 jpg
│  └─ ...
├─ prompts.md
├─ publication-copy.md
└─ manifest.json
```

## 8. 微信公众号发布

1. 解压 ZIP 发布包。
2. 按顺序上传 `images/` 中的 6 张图片。
3. 将 `publication-copy.md` 中的文案复制到文章正文。
4. 补充必要的来源、作者和版权说明。
5. 发布前复核文字版本、作者署名、图片顺序和版权状态。

## 9. 推荐文件管理

```text
散文名称/
├─ source/
│  ├─ 原文.txt
│  └─ 来源链接.txt
├─ generated-images/
│  ├─ 01-cover.png
│  └─ ...
├─ exports/
│  └─ 散文名称-微信贴图发布包.zip
└─ notes/
   └─ 修改记录.md
```

不要把 `.dev.vars`、DeepSeek API Key、D1 备份或用户原文备份提交到 Git。

## 10. 常见问题

### 页面显示 401

Access 登录状态失效。重新打开正式地址并完成邮箱验证。

### AI 分析失败

检查 Access 登录、DeepSeek Secret、账户余额、原文长度和每日调用限额。失败时原有图卡不会被覆盖。

### 图片上传失败

检查文件格式、大小、像素总量、文件完整性和登录状态。

### 导出按钮不可用

通常是图卡数量不足 6 张、存在未匹配底图、原文短摘验证失败或图片仍在上传。

### 数据保存位置

- D1：项目、完整原文、图卡、提示词和排版配置
- R2：原始底图和排版成品图

确认顶部显示 `已保存到 D1` 或 `图片已保存到 R2`，再关闭页面。
